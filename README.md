# 微聊本机演示版

## 启动

在 `E:\voice-chat-miniapp` 目录运行：

```bash
npm install
npm run social
```

然后打开：`http://127.0.0.1:8787`

## 双用户演示

1. 用普通窗口注册第一个账号。
2. 用无痕窗口注册第二个账号。
3. 第一个账号搜索第二个用户名并发送好友申请。
4. 第二个账号在“好友申请”中接受。
5. 双方可以发送文字、图片，并发起/接听实时语音通话。

## 数据位置

- SQLite 数据库：`social-demo/data/social.db`
- 图片：`social-demo/data/uploads/`

这是本机演示版：账号和消息仅保存在本机，不适合直接暴露到公网。麦克风在 `127.0.0.1` 可用；若从其他设备通过局域网 IP 访问，浏览器通常要求 HTTPS 才允许麦克风。

## Render 在线演示

仓库根目录包含 `render.yaml`，可部署为 Render Web Service。在线免费演示使用临时文件系统：服务重启或重新部署后，账号、好友、消息和图片可能被清空。线上环境会自动提供 HTTPS，可使用麦克风语音通话。
